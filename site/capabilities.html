Core VM & AIR

Accumulator + register ISA

IMPLEMENTED

INIT/ADD/SUB/MUL, forward-only JZ/JNZ, LOAD/STORE across 4 fixed registers -- a real interpreter and a .zkasm assembly format.

▼ click to expand

STARK proof via Winterfell

IMPLEMENTED

A from-scratch AIR binding a proof to one exact program and its actual execution. Real proof, ~11 KB, ~5.5ms to verify.

▼ click to expand

No-secret-witness soundness design

IMPLEMENTED

Because the program and inputs are fully public, the verifier re-executes and asserts almost everything directly -- no lookup or permutation argument needed.

▼ click to expand

One-hot selectors instead of a mux

IMPLEMENTED

Seven opcode-selector columns and a register selector, multiplied algebraically instead of using a lookup/mux gadget.

Interfaces

CLI: run / prove / verify / deploy / demo

IMPLEMENTED

Five subcommands, one binary. deploy pushes a program to a running zkvm-host-server and verifies the returned proof locally.

On-Chain & Trust

ProofOrchestrator + AttestedVerifier

IMPLEMENTED

A task/reward lifecycle contract with zero verification logic of its own, plus an explicit, documented trust-bridge verifier.

▼ click to expand

UnimplementedStarkVerifier

IMPLEMENTED

Reverts, always -- the honest state of "no real on-chain verifier exists yet," instead of a stub that quietly returns true.

Foundry test suite

IMPLEMENTED

8 real tests: the unimplemented verifier makes payout impossible, the attested happy path, and every failure mode (wrong proof, wrong caller, double-fulfillment, unclaimed tasks).
