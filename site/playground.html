Real opcodes supported here

INIT n — set the accumulator to n
ADD n — acc = acc + n
SUB n — acc = acc − n
MUL n — acc = acc × n

The real ISA also has JZ/JNZ (forward-only conditional jumps) and LOAD/STORE (4 fixed registers) — not simulated in this in-browser demo, but fully real in the actual VM. See the architecture page.
